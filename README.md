# 👑 Niklas 30 – Was soll Niklas als Nächstes tun?

Eine Progressive Web App (PWA) für den 30. Geburtstag. Edler Gold/Schwarz-Look.

## 🚀 Deployment auf GitHub Pages

1. Neues Repository auf GitHub erstellen (z.B. `niklas-geburtstag`)
2. Alle Dateien in das Repository hochladen
3. **Settings → Pages → Source: Deploy from branch → main → / (root)**
4. Nach ca. 1 Minute erreichbar unter:
   `https://DEIN-USERNAME.github.io/niklas-geburtstag/`

## 📱 Als App installieren

**iPhone/iPad:** Safari → Teilen → „Zum Home-Bildschirm"
**Android:** Chrome → Menü → „App installieren"
**Desktop:** Chrome/Edge → Installations-Symbol in der Adressleiste
